# 📝 MCQ Generator

An **AI-powered MCQ Generator** that automatically creates multiple-choice questions from a given topic or study material. It helps students quickly prepare for exams, practice concepts, and test their knowledge.

## 🚀 Features

* 🤖 AI-generated multiple-choice questions
* 📚 Generate questions from different topics
* ❓ Multiple options for each question
* ✅ Displays the correct answer
* 💡 Provides explanations for answers
* 🎯 Useful for exam preparation and self-assessment
* 🖥️ Simple and user-friendly interface

## 🛠️ Technologies Used

* **Python**
* **Generative AI / LLM**
* **Streamlit**
* **Prompt Engineering**

## 🔄 How It Works

```text
Enter Topic / Study Material
            ↓
      AI Processing
            ↓
    Question Generation
            ↓
      MCQ + Options
            ↓
 Correct Answer + Explanation
```

## 💡 Example

### Input

```text
Topic: Artificial Intelligence
```

### Generated Question

**What is Artificial Intelligence?**

A. A computer hardware component
B. The simulation of human intelligence by machines
C. A programming language
D. A database system

**Correct Answer:** B

**Explanation:** Artificial Intelligence enables machines to perform tasks that normally require human intelligence, such as learning, reasoning, and decision-making.
